# 本机引擎与远程主机

DSH 可以直接运行在这台手机上（本机引擎），也可以运行在你的电脑或服务器上，由手机远程连接。对话、工作区和插件都属于各自的主机。

## iPhone 后台运行

离开 App 后，本机引擎只有在系统实际允许后台计算时才继续。可见、正在播放且未被系统挂起的宠物画中画，以及系统已接受的持续处理任务，是两个独立来源；其中一个结束不会误清另一个。开启画中画开关、下载好素材或显示过一次，都不能证明它现在仍有效。

宠物画中画默认关闭，手机操控不再把它或宠物选择作为前置条件；原生手机任务会主动申请系统持续运行。若你主动在手机操控页开启画中画，并选择任务结束后也留着，也可把它用于普通本机对话的额外后台支持。先在前台让宠物画中画真正出现，再切到其他应用。关闭、暂停、锁屏或音频中断后，若没有其他有效的系统后台许可，引擎会在下一次工具边界暂停；系统仍可能提前挂起或结束 App，不保证永久在线。

画中画不会批准工具、解除安全模式或继续你手动暂停的手机任务。需要确认时仍回到 App；恢复画中画不是同意上一份请求。远程主机上的引擎不靠 iPhone 的画中画维持运行。

## iPhone 的 Linux 与 Python

<!-- nav: commonSettings,hubSettingsEngine -->
`设置 › 本机引擎` · [打开](dshgo://open/engine)

在 iPhone 上，进入该页的「Linux 环境」小节。

安装可选环境，然后重启本机引擎。它使用 Alpine；安装完成不代表已经装了 Python、git 或 rg。没有安装或环境被暂停时，普通命令的可用范围不同，先查看这一项的实际状态。

可以在本机对话里明确要求安装 Python 和 pip：

```sh
apk add python3 py3-pip
python3 --version
python3 -m pip --version
```

安装软件会修改 Linux 系统，需要批准这次系统写入；工作区写入许可不能代替它。下载、安装或运行失败时查看真实报错，不要通过重置、卸载或改配对设置来解决缺包。Linux 环境不提供任意访问其他 iOS App 的能力。

## 本机还是远程

第一次打开 App 时选择怎么用：

- **本机**：在手机上安装运行环境，全程在本机完成。选项里会写明需要的存储空间和内存。
- **远程主机**：连接电脑或服务器上的 DSH，不在手机上安装。手机内存或存储不够时会推荐这一项。
- **和角色聊天**：只用酒馆，什么都不装，直接进酒馆，以后打开 App 也先进酒馆。从 DeepSeek 接回对话也走这里。

之后随时可以补装本机环境：在引擎页点**安装运行环境**，或在切换主机时点**本机**。装好后自动启动。

## 本机引擎

<!-- nav: commonSettings,hubSettingsEngine -->
`设置 › 本机引擎` · [打开](dshgo://open/engine)

- **启动**、**停止**、**重启**：停止前会确认；停止和重启都会中断进行中的对话。
- 启动失败时，页面显示失败原因和对应的修复按钮，如重试、**以安全模式启动**、查看日志。
- **打开 App 时自动启动**：默认开启。只要装了本机环境，即使在用远程主机，打开 App 时也会启动本机引擎；不需要时关闭。
- **自动进入安全模式**：默认开启。连续两次启动失败后，自动不加载插件启动。
- **以安全模式启动**：手动进入安全模式；修好后点**恢复正常模式**。进入和退出都会重启引擎。
- **日志**：引擎的实时输出。
- **后台运行**、**诊断**：见 [常见问题](11-faq.md)。

## 更新与已安装工具

普通引擎更新只替换 App 管理的引擎组件，不重建现有 Linux 系统；系统里的 gh 等 apt 工具、默认位置的 npm 全局包、Python/pip 包、配置和工作区都会保留。内置 DSH、Node、pnpm、桥接与它们的专用目录仍由 App 更新，不要把自己的软件装进这些目录。Node 版本变化后，第三方原生扩展仍可能需要重新编译，保留文件不代表所有扩展自动兼容。

旧版本会先核对架构、Ubuntu 版本和 Python，再采用原环境。无法确认兼容、更新清单损坏或遗留进程未停止时，更新会停止并说明原因，不会自动清空或重建环境。升级被中断时请重试安装，不要手动删除恢复目录。

更换基础系统前先做完整备份，不要把诊断包或导出的对话日志当作环境备份。完整备份应在停止引擎后包含 Linux 文件、权限、符号链接、包数据库与家目录，保存在运行环境之外，并核对可读性和恢复步骤。App 目前没有一键完整环境备份/恢复功能；遇到不兼容提示时先保留现场并联系维护者协助离线导出，不要直接重置或卸载 App。保留原环境也不是独立备份，清除 App 数据或卸载 App 仍会丢失它。

## 重置运行环境

<!-- nav: commonSettings,hubSettingsEngine,phoneEngineReset -->
`设置 › 本机引擎 › 重置运行环境`

删除本机数据后重新安装运行环境，用于修复无法启动的环境。确认框里可选：

- **保留界面配置和技能**：默认勾选。
- **保留已装插件和设置**：默认不勾选。

按默认确认，会删除对话、工作区、插件和设置，自定义模型渠道也在其中；App 里保存的 DeepSeek Key 会自动补回。家目录（`/root`）里没有保留的内容也会一起删除，包括工作区里的文件、`AGENTS.md`，以及插件自己存的数据（比如记忆）。确认框会写明这次删除的范围，点**删除并重置**后 App 自动重新安装。重置无法撤销，需要的对话先用 `/export` 或「全部功能」里的**导出对话日志**导出。

## 卸载运行环境

<!-- nav: commonSettings,hubSettingsEngine,localEnvUninstall -->
`设置 › 本机引擎 › 卸载运行环境`

## 添加 SSH 主机

那台主机需要开着 SSH，并装好 DSH（`npm i -g @deepseek-ai/dsh`）。

1. 在远程主机页点**添加 SSH 主机**。
2. 填写**主机**、**用户名**，**端口**默认 22。名称可以留空。
3. 选择**密码**或**私钥**登录。私钥可以**从文件导入**，有口令时填**私钥密码（可选）**。密码和私钥只保存在这台手机上。
4. **实例管理**默认**托管启动**：**启动命令**默认 `dsh web`；用 nvm 安装的 DSH 可以填完整路径。已有自己管理的实例时选**只连接**，填写**远端 DSH 端口**和该实例启动链接中的 **DSH 登录令牌**。**工作目录（可选）**是新对话的默认目录；只连接模式请用绝对路径。
5. 点**测试连接**。首次连接会弹出**信任这台主机？**：在那台主机上核对指纹，一致再点**信任并连接**。
6. 点**保存**，再在主机列表里选中它。

托管模式的测试连接会启动或复用远端 DSH，测试结束后它继续运行。**只连接**只建立 SSH 隧道到远端 `127.0.0.1` 的指定端口，不自动查找实例，不执行启动、停止或重启，不读写托管状态文件；请先在远端启动实例并保持运行。连接失败时检查端口与令牌，App 不会用重启修复它。令牌和 SSH 密码、私钥一样，仅保存在手机安全存储中。

托管模式发现仍活着但启动命令不同、日志丢失的实例时，会明确停止连接而不是自动杀掉它；登录令牌被拒绝、复用端口拒连也不会授权重启。先检查配置或改用**只连接**；确实要替换 App 记录的实例时，在编辑主机的 DSH 区选择**重启托管 DSH**，确认后才停止并重启。此操作可能中断其他客户端和进行中的对话，普通**测试连接**不会执行它。已确认死亡的托管进程仍可自动补启。

**SSH 压缩**默认开启，协商认证后压缩；服务器不支持时保持未压缩传输。可在主机编辑页关闭，保存后重新建立 SSH 连接生效。

修改或删除：点主机右侧的**编辑**按钮，进入**编辑主机**，底部是**删除这台主机**。删除只移除手机上保存的设置、密码、私钥和登录令牌，远端的 DSH 和对话不受影响。

## 配对电脑

不需要账号，也不用配置网络：用电脑上访问入口显示的配对码连上它，之后直接 HTTP 连接，不走 SSH。

1. 在那台电脑上打开 DSH 的访问入口，让它显示配对二维码或配对码。
2. 在远程主机页点**添加配对电脑**，再选**扫码**、**粘贴链接**或**手输配对码**；读到的配对信息会直接开始配对并连接，不用再确认一次。
3. 连上后在「配对电脑」里选中它。配对码 5 分钟内有效且只能用一次；连上之后这台电脑保持 30 天，不用每次再输码。

电脑改名、移除都在那一行上长按打开。移除只抹掉手机上的配对凭据，电脑本身不受影响。

扫码由系统扫码页或相机提供；没有相机权限时仍可以用**粘贴链接**或**手输配对码**。手机操控的文字识别是另一个开关，扫码不会改动它；SDK 的统计说明见[常见问题](11-faq.md#本机文字识别与-google-ml-kit)。

## 打开远程主机的网页版

<!-- nav: commonSettings,hubSettingsInterface,hubInterfaceOpenWeb -->
`设置 › 界面 › 打开网页版`

SSH 主机连上后，网页版和其他主机一样打开：点对话列表顶部「新对话」旁的按钮切到网页界面，或用这里、「全部功能」里的**网页版**只打开一次（见[网页模式](05-web.md)）。网页版走 SSH 隧道，在 App 内置页面里打开。

配对的电脑暂时没有内置网页版入口；需要直接用电脑上的 DSH Web，在那台电脑上打开。
